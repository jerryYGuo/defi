# 链上牌桌 / DeFi Desk

一个单文件的 DeFi 研究台网页，从资深玩家的视角分析链上项目：实时拉取数据、给协议打分、
把「补贴堆出来的假增长」和「有真实交易量支撑的趋势标的」分开。

## 打开方式

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
xdg-open index.html      # Linux

# 方式二：起个本地服务（推荐，避免个别浏览器对 file:// 的跨域限制）
npx http-server -p 8080 . && open http://127.0.0.1:8080/index.html
```

也可以在仓库 Settings → Pages 里把分支发布成 GitHub Pages，得到一个常驻网址。

`index.html` 没有任何构建步骤和依赖，所有数据由**你的浏览器直接向 DefiLlama 请求**，
不经过任何中间服务器。注意：受限的嵌入环境（部分在线沙箱、企业代理）会拦截跨域请求，
此时页面会提示数据源不可达——换用本地浏览器打开即可。

## 核心逻辑：一条四层因果链

DeFi 的因果链只有四层，**下层的结论必须以上层成立为前提**。绝大多数误判，
都是拿第一层的数字（TVL 涨了）去支撑第四层的结论（所以该买）。

| 层 | 指标 | 它回答什么 | 断掉意味着 |
|---|---|---|---|
| 01 钱 | 稳定币供给 30 日变化 | 场内资金还在增加吗 | 存量博弈，后三层再好也没有整体行情 |
| 02 用 | 月度 DEX 量 ÷ TVL | 这些钱在周转吗 | 钱停在池子里等激励，没变成链上活动 |
| 03 赚 | **剪刀差 = 费用增速 − TVL 增速** | 收入跑赢规模了吗 | 新增资金是不付费的那部分，收入被稀释 |
| 04 值 | 板块 P/F | 价格是否已透支 | 基本面成立但已被定价，超额收益在二线 |

页面会沿这条链找**第一个断点**，并由断点位置推出当下的操作倾向。

### 为什么剪刀差是核心

TVL 能靠激励堆、靠币价涨、靠重复计算虚增；交易量能靠洗量刷。
但费用是用户真金白银付出去的——**刷费用等于自己烧钱**。
把两个可操纵的数字相减，得到一个难被操纵的结论：

- 剪刀差为正 → 每 1 美元锁仓赚到的钱在变多，增长来自「用的人更多」，可以外推
- 剪刀差为负 → 规模扩张快过收入，增长来自「堆进来的钱更多」，流入一停就回吐

## 页面模块

| 模块 | 回答的问题 |
|---|---|
| 主线：钱 → 用 → 赚 → 值 | 这条链断在哪一层，因此现在该进攻还是防守 |
| 背离：TVL vs 稳定币 | TVL 上行而稳定币走平，涨的就是价格不是资金 |
| 趋势雷达 | 同一条链落到单个协议：按剪刀差、年化费率、P/F 排序，逐行定位断点 |
| 资金流向 | 公链与赛道的 7 日资金净变化，看轮动 |
| 收益机会台 | 每个池子拆出「真实收益」与「代币补贴」，补贴占比越高保质期越短 |
| 方法论 | 全部计算口径、TVL 会骗人的四种方式、以及这些数字的边界 |

## 数据口径

- 数据源：DefiLlama 公开 API（`protocols` / `overview/fees` / `overview/dexs` / `stablecoins` / `yields`）
- 默认 5 分钟自动刷新，可切 1 / 15 分钟或手动；标签页不可见时暂停轮询
- 分项得分用 `tanh` 做饱和归一化，缺失项不补零而是按比例重分配权重
- 增速优先用 30 日口径；数据源未提供时降级为「近 7 日日均 vs 近 30 日日均」的加速度口径，页面会标注
- P/F 20x / 45x、剪刀差 ±2pp 等分界是经验区间而非硬阈值，不同周期应当平移
- 部分协议的费用按母协议口径归集（多版本合计），表内以 `≈` 标注，展开行有说明
- 自选清单存在浏览器 localStorage，不上传
